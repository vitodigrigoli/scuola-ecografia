Etichetta a pillola non cliccabile, in tre varianti distinte per significato — non intercambiabili tra loro. Learnn usa un'emoji davanti al testo (es. "🎯 Advertising"); qui l'emoji è sostituita da un'icona SVG del set `Icons`, per istruzione esplicita del cliente.

**Fornisci:** testo breve, spesso con un'icona `tag`/`zap` davanti; variante: `neutral` (bordo discreto, per un tag categoria — icona `tag`), `accent` (viola pieno, per l'unico elemento di massima enfasi in vista — icona `zap`), `ai` (viola periwinkle tenue, riservato a contenuti generati o assistiti da un sistema automatico).

**Quando usarlo:** `neutral` sulle course card per l'ambito anatomico/distretto. `accent` una sola volta per vista (il piano/pacchetto consigliato). `ai` solo quando il contenuto è realmente generato da un assistente automatico — mai come badge decorativo generico.

**Non fare:** non usare `accent` per più di un badge nella stessa vista, altrimenti perde significato di "scelta consigliata". Non tornare a un'emoji davanti al testo: l'icona è sempre SVG, mai un carattere emoji o un simbolo tipografico decorativo.
